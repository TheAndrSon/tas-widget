# Логика пламбоба: техническая фиксация

Документ фиксирует игровую механику, которая уже перенесена в старый проект.
Пользовательские правила и список наград: `docs/SIMS_GAME.md`.

## Состояние

```ts
interface SimsMood {
  mood: number
  hunger: number
  energy: number
  fun: number
  social: number
  hygiene: number
  points: number
  updatedAt: number
  stats: SimsStats
  unlocked: string[]
}
```

`SimsStats` хранит действия, дни, хорошие/идеальные дни, лучший mood, заработанные
звёзды, число ухудшений, действия по каждой потребности, дневные минимумы и серии,
время последнего штрафа и бонуса.

Состояние хранится по группам: `state.sims[groupId]`. Виджеты с одинаковым `groupId`
делят одно состояние. Группа задаётся в настройках экземпляра.

## Действия

Пять потребностей: `hunger`, `social`, `hygiene`, `energy`, `fun`.
Кнопки вызывают `simsAction(groupId, action, difficulty, need)`.

| Действие                         | Лайт | Хард                    |
| -------------------------------- | ---- | ----------------------- |
| Прибавка к выбранной потребности | +24  | +16                     |
| Звёзды                           | +2   | +1                      |
| Побочный эффект                  | нет  | −4 к другой потребности |

Побочная потребность в харде:

- `energy` → `hunger`
- `fun` → `energy`
- остальные → `fun`

«Ухудшить» снижает выбранную потребность на 18 (лайт) / 24 (хард) и списывает 1★.
Режим «Ухудшить» в UI не сбрасывается после одного клика: кнопка меняется на
«Улучшить», и только она возвращает обычный режим. В `SimsMenu` и `SimsWidget`
это локальный `useState`.

## Просадка

`decayMood(mood, now, difficulty)` списывает целые прошедшие часы, максимум 168.

- 20:00–10:00: −1 в час (хард: −2)
- 10:00–20:00: −6 в час

За полные сутки 100% → примерно 26% в лайт-режиме. Остаток меньше часа не списывается:
`updatedAt` сдвигается на число полных часов, поэтому дробный остаток сохраняется.

## Звёзды

- Действие: +2★ (лайт) / +1★ (хард).
- Бонус: mood ≥ 80 раз в 6 часов, +3★ (лайт) / +2★ (хард).
- Штраф: если потребность ≤ 15, раз в 3 часа −1★ за каждую такую потребность.
- «Ухудшить»: −1★.
- `points` не может уйти ниже 0.

## Дни и достижения

При смене календарного дня:

- `days += 1`;
- если mood ≥ 70, `goodDays += 1`;
- если все потребности ≥ 80, `perfectDays += 1`;
- серия каждой потребности увеличивается, если её дневной минимум ≥ 30, иначе сбрасывается;
- дневные минимумы начинаются заново.

`evaluateAchievements` проверяет все определения `SIMS_ACHIEVEMENTS` после каждого
действия и просадки. Открытые ID хранятся в `mood.unlocked`.

## Награды

Полный список с условиями — в `docs/SIMS_GAME.md` и в `SIMS_ACHIEVEMENTS`.
Всего 22: 5 базовых, 12 мемных/Sims, 5 по потребностям.

## Где менять баланс

- Прибавки, побочные эффекты, штрафы — `simsDo` в `src/shared/sims.ts`.
- Просадка и бонусы — `decayMood` там же.
- Награды — массив `SIMS_ACHIEVEMENTS` там же.
- Стартовые значения — `DEFAULT_SIMS_MOOD` в `src/shared/defaults.ts`.
- Подписи сложности — `SimsPanel`/`SimsWidget` (метки «лайт/хард»).

## Быстрая проверка после изменений

1. `npm run typecheck` в `D:\OpenCode_Projects\Widget`.
2. `npm run build`.
3. Запустить `npm run dev`.
4. В блоке потребностей:
   - нажать «Голод» — значение +24, звёзды +2 в лайт;
   - включить «Ухудшить», дважды нажать «Голод» — значение падает каждый раз,
     режим остаётся, кнопка называется «Улучшить»;
   - нажать «Улучшить» — кнопки снова повышают;
   - открыть 🏆 в меню — счётчик и список наград.
5. Переключить сложность на хард: прибавка +16, звёзды +1, есть побочный минус.
6. Проверить общую группу: изменения в блоке потребностей отражаются на пламбобе.

## Важно

- Не менять сигнатуру `simsAction` без обновления `preload` и `shared/types.ts`
  (`WidgetsApi.simsAction`).
- `need` в `sims:action` необязателен: без него «Ухудшить» снижает все потребности
  (обратная совместимость со старым меню).
- Старые сохранения без `stats`/`unlocked` нормализуются в `normalizeSims`.
