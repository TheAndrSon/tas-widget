# HANDOFF

## Состояние на 2026-11-10

Каркас приложения готов и проверен: `typecheck`, `build`, запуск Electron.
Системный виджет отображает CPU, ОЗУ и диски в реальном времени (проверено через CDP).

## Что сделано

- Electron 45 + React 19 + TS, electron-vite 6, Vite 8, `systeminformation`.
- Окна виджетов: прозрачные, без рамки, always-on-top, перетаскивание, сохранение позиции.
- Трей: чекбоксы виджетов, «Открыть все», «Закрыть все», «Выход».
- Настройки: `%APPDATA%\tas-widgets\settings.json`, отдельно от старого TAS Widget.
- IPC-контракт: `settings:get/patch`, `widget:open/close`, `app:quit`, `ui:context-menu`, `system:sample`.
- Системный виджет: CPU/RAM/диски, период опроса из настроек.
- Каталог виджетов с флагами готовности: `system` — ready, остальные — planned.
- Документация: `AGENTS.md`, `docs/PROJECT_GUIDE.md`, `README.md`.

## Проверено

- `npm run typecheck` — без ошибок.
- `npm run build` — out/main, out/preload, out/renderer.
- Запуск `electron .`: окно «TAS Widget», `settings.json` создаётся, CDP-проба вернула живые данные и `window.api`.

## Следующий шаг

Сессия 1 — окно настроек (фундамент):

1. Отдельное окно настроек, вкладки по виджетам, стилевые токены.

Дальше по роадмапу: музыка (SMTC) → погода (мультиэкземпляры) → эквалайзер → пламбоб (мультиэкземпляры) → упаковка.

## Решения по процессу

- Один виджет за сессию, последовательно: параллельные сессии конфликтуют (single instance, порт 5173, общие `shared/*`, `ipc.ts`, `App.tsx`).
- Параллельно можно только читать старый код субагентом, без правок.
- Глубина — минимум, но качественно; настройки в отдельном окне; приоритет стабильности.
