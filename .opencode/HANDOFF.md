# HANDOFF

## Состояние на 2026-11-11

Каркас, окно настроек, музыка, погода и эквалайзер готовы. Проверено: `typecheck`, `build`,
запуск Electron, CDP-проба (окна, настройки, живые изменения, SMTC, погода, эквалайзер).

## Что сделано

- Electron 45 + React 19 + TS, electron-vite 6, Vite 8, `systeminformation`.
- Окна виджетов: прозрачные, без рамки, always-on-top, перетаскивание, сохранение позиции.
- Трей: чекбоксы виджетов, подменю «Погода» с городами, «Открыть все», «Закрыть все»,
  «Настройки…», «Выход».
- Настройки: `%APPDATA%\tas-widgets\settings.json`, отдельно от старого TAS Widget.
- IPC: `settings:get/patch/open`, `widget:open/close`, `app:quit`, `ui:context-menu`,
  `system:sample`, `weather:add/remove/open/close/patch`.
- Системный виджет: CPU/RAM/диски, период опроса из настроек.
- Окно настроек: вкладки по виджетам; готовы «Система», «Музыка», «Погода»;
  planned-вкладки «Эквалайзер» и «Пламбоб».
- Общие стили: `styles/tokens.css` (цвета, радиусы, тени, шрифт), `settings/settings.css`.
- Открытие настроек: трей, правый клик по виджету, `window.api.openSettings()`.
- Документация: `AGENTS.md`, `docs/PROJECT_GUIDE.md`, `README.md`.
- Музыка (SMTC): `main/music.ts`, `main/paths.ts`, `resources/smtc.ps1`,
  `resources/smtc-control.ps1`. Старт при открытии виджета, стоп при закрытии.
- `shared/types.ts`: `MusicSettings`, `MusicStatus`, `MusicSnapshot`, `MusicAction`.
- IPC: `music:get`, `music:control`, broadcast `music:sample`; `settings:changed` для живых
  настроек виджетов.
- `MusicWidget.tsx` + `MusicWidget.css`: обложка, трек, плеер, прогресс, перемотка, кнопки.
  Порт старого вида, зелёный акцент, фикс залипания фокуса кнопок (`blur` + `:focus-visible`).
- Вкладка «Музыка» в настройках: вкл/выкл виджета, обложка, прогресс, кнопки, название плеера.
- Погода: `main/weather.ts` (Open-Meteo, MET Norway, wttr.in, Яндекс с ключом, резервный
  7timer), `shared/sun.ts`, `shared/weatherCodes.ts`, `shared/date.ts`, поиск города.
- `WeatherWidget.tsx` + CSS: текущая погода, ощущается, ветер, влажность, прогноз 3/5 дней,
  солнце (дуга/компактно), атмосфера по времени суток. Эффекты: дождь, снег, туман, гроза;
  облака и солнечный блик убраны.
- Мультигород: до 5 погодных окон, у каждого свой город, позиция, вкл/выкл и настройки
  (`weather.instances`); окна раскладываются колонкой с переносом влево.
- Атмосфера: 4 бегунка интенсивности (рассвет/день/закат/ночь), значение 0..1 на город.
- Вкладка «Погода»: чипы городов, добавление/удаление, поиск и пресеты, единицы, источник,
  ключ Яндекса, атмосфера и её интенсивность, прогноз, режим солнца, отображение метрик.
- Эквалайзер переделан заново: `renderer/audio.ts` (loopback через `getDisplayMedia`),
  новый `Visualizer.tsx` (столбики, радиальные, линия, точки, искры, волны),
  `EqualizerWidget.tsx` + CSS.
- Main: `setDisplayMediaRequestHandler` с `audio: 'loopback'`, разрешения media/display-capture,
  `app:displays`; окна эквалайзера создаются `resizable` и сохраняют реальный размер.
- Несколько копий эквалайзера (до 5): `equalizer.instances`, каждая со своими настройками,
  позицией и размером; трей с подменю копий.
- Оконный и безоконный режим: безоконный — прозрачное окно без фона, рамки, тени и отступов.
- Кнопка «По центру монитора» и выбор монитора.
- Визуализатор: количество и толщина столбиков, зазор, ось отражения и её положение,
  поворот, отражения X/Y, размер/скорость искр, количество/скорость/толщина волн,
  интенсивность, высота, частоты и шкала.
- Убраны: док по краям, выравнивание по краю, режим обводки, палитра «Перелив».
- Блокировка окон: `locked` у каждого виджета и копии; в заблокированном режиме окно
  не перетаскивается, кнопки музыки и перемотка остаются активными.
- Слои: `layer` 0–3 (0 — рабочий стол, 1–3 — поверх остальных окон), порядок
  пересобирается через `moveTop`.
- Глобальные действия в настройках: «Заблокировать все», «На рабочий стол»,
  «Поверх всех», «Сбросить позиции».
- У каждого окна: переключатель блокировки, выбор слоя и кнопка сброса положения.
- Стили окон (`WindowStyle`): безоконный режим, скругление, градиент и прозрачность фона,
  обводка под/над окном с неоновым свечением, имитация лампы (мерцание), свечение окна,
  световой акцент (кроме эквалайзера).
- Окна увеличены на 48 px по каждой оси, внутри `.widget-root` отступ 24 px — свечение
  до 24 px не обрезается, при этом окно можно двигать за край экрана.
- Пресеты «Стекло», «Неон», «Изумруд», «Закат», «Минимал», сохранение своих стилей,
  удаление и применение стиля ко всем виджетам.
- В `WindowStyle` уже есть массив `images` под два слоя (кадрирование и библиотека — этап 1b-2).
- `package.json`: `build.extraResources` для `smtc*.ps1` (упаковка).

## Проверено

- `npm run typecheck` — без ошибок.
- `npm run build` — main, preload, renderer, settings.html.
- Запуск `electron .`: окно «TAS Widget», `settings.json` создаётся.
- CDP: окно настроек открывается, вкладки и текст на месте; смена периода опроса
  сохраняется в `settings.json` (проверено 5000 мс, затем возвращено 2000).
- Музыка: окно 340×150, трек и обложка приходят из Chrome SMTC; переключение
  `showArt` в настройках применяется на живом виджете; закрытие виджета завершает
  `smtc.ps1`; вкладка «Музыка» без бейджа «скоро».
- Погода: окно 320×300, Москва по умолчанию; данные Open-Meteo, солнце-дуга, прогноз,
  дождевой эффект для Лондона; поиск города вернул Лондон/Онтарио/Кентукки; смена города,
  прогноза, режима солнца и атмосферы применяется на живом окне.
- Мультигород: до 4 окон одновременно (Москва, Берлин, Лондон, Токио) — все открылись,
  позиции не пересеклись (2 ряда, затем колонка слева); у Лондона °F, у Москвы °C.
- Атмосфера: средняя альфа canvas при ночной интенсивности 0.15 — 13, при 1.0 — 82.
- Добавление города через настройки (поиск «Берлин») открыло окно и выбрало новый город.
- Эквалайзер: spectrum-картинка в режиме «Столбики» подтверждает loopback-звук.
- Безоконный режим: фон прозрачный, рамка 0 px, canvas занимает всё окно.
- Реальное изменение размера: `resizeTo(600, 300)` дало canvas 600×300 и сохранилось
  в настройках копии.
- Копии: вторая копия открылась отдельным окном (360×200, позиция 24×596),
  центрирование дало 780×416 на мониторе 1920×1080.
- Режимы: радиальные, столбики с отражением, волны и искры отрисовались вживую.
- Блокировка: у system/music появился класс `is-locked`, `-webkit-app-region: no-drag`;
  кнопки музыки остались `no-drag`.
- Сброс положения: system вернулся в 1616×24, music — в 1556×232.
- Глобальные действия: «Заблокировать все», слои и сброс позиций отработали на всех окнах.
- Стили: окно system 328×244 при контенте 280×196 (padding 24 px); пресет «Неон» дал
  обводку и свечение без обрезки; безоконный режим — фон прозрачный, shadow none.
- Настройки: все 5 пресетов, сохранение стиля и кнопка «Ко всем виджетам» на месте,
  горизонтальной прокрутки нет.

## Решения по процессу

- Один виджет за сессию, последовательно: параллельные сессии конфликтуют (single instance,
  порт 5173, общие `shared/*`, `ipc.ts`, `App.tsx`).
- Параллельно можно только читать старый код субагентом, без правок.
- Глубина — минимум, но качественно; настройки в отдельном окне; приоритет стабильности.
