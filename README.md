# TAS Widget (архив)

> **Ветка `v2` остановлена.** Проект не оправдал ожиданий по стабильности и внешнему виду.
> Актуальная разработка — в старом проекте (`main`). Подробнее: [ARCHIVED.md](ARCHIVED.md).

Десктопные виджеты для Windows на Electron + React + TypeScript: музыка, система, погода,
эквалайзер и пламбоб. Прозрачные окна, всегда сверху, управление из трея.

## Запуск

```bash
npm install
npm run dev
```

Проверка: `npm run typecheck` и `npm run build`.

## Статус

Готовы система, музыка (SMTC), погода (несколько городов), эквалайзер и пламбоб с потребностями и наградами.
