# TAS Widget

Десктопные виджеты для Windows на Electron + React + TypeScript: музыка, система, погода,
эквалайзер и пламбоб. Прозрачные окна, всегда сверху, управление из трея.

## Запуск

```bash
npm install
npm run dev
```

Проверка: `npm run typecheck` и `npm run build`.

## Статус

Готов каркас и системный виджет. Остальные виджеты — по плану в `docs/PROJECT_GUIDE.md`.
